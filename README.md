世界観とキャラクター

タイトル案：『いろどりの森 クルリとなかまたち』

あらすじ： 色がなくなってしまった「いろどりの森」。小さな雲の妖精クルリは、色を集めると元気になります。動物たちが色のものを見つけて、クルリに色を分けてあげます。

キャラ	特徴（毎回のプロンプトにコピペして一貫性を保つ）
ポポ（うさぎ）	丸い体、クリーム色の毛、長い垂れ耳、大きな黒い点の目、小さな茶色のポシェット。元気で好奇心いっぱい
コロ（こぐま）	丸いベージュの赤ちゃんぐま、小さな丸い耳、ふわふわのお腹。おっとりした性格
パオ（ぞう）	小さな薄いグレーの赤ちゃんぞう、大きな耳、くるんとした鼻。恥ずかしがりやだが優しい
クルリ（雲の妖精）	手のひらサイズの白い雲、丸い顔、ほっぺが丸い。最初は真っ白で、色をもらうごとにほっぺと体に色が増える

共通スタイル指示（全プロンプトの末尾に付ける）：
2D flat cartoon style, soft rounded shapes, gentle pastel storybook look, children's educational animation, clean outlines, smooth motion, no text, no letters, no subtitles

共通ネガティブ指定：

色を教える動画なので、キャラ自身の色は「クリーム・ベージュ・グレー・白」の中間色にして、学習する色と混ざらないようにしています。

シーン1：オープニング「いろがない！」（0:00–0:10）
登場： ポポ、コロ、パオ、クルリ
背景： 白とグレーのやさしい森。木も花も空も色がなく、うっすら輪郭だけ
動き：
0–3秒：ポポが森の入口にぴょんと跳ねて登場
3–6秒：コロとパオが左右から顔を出し、きょろきょろ見回す
6–10秒：しょんぼりした白いクルリがふわっと降りてきて、3匹が駆け寄る
カメラ： 森全体のロングショット（0–3秒）→ 3匹へゆっくりズームイン（3–6秒）→ クルリのアップへ（6–10秒）

3匹：「いいよ！　いっしょに　さがそう！」
